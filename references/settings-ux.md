# Settings UX rules (binding)

- Page: large title + one-line subtitle; grouped sidebar with coloured icons + search; Restore Defaults at the end.
- Row: coloured icon + title + one grey sentence that states the effect **and its cost** ("Needs Accessibility",
  "Uses the network", "Stays on this Mac").
- Dependent rows dimmed, never hidden. Sliders show the value with −/+. Segmented control for 2–4 options.
- Destructive actions red with inline confirm (strong confirm for uninstall). Status read-outs inline.
- Changes apply live, no restart. Export / import settings. A Permissions page with status + "Open System Settings".
- Suggestions card for missing permissions with a badge on the sidebar.
